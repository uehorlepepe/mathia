# Figures

This folder contains the five figures used in the README and the results pages. They are committed to the repository so the project can be read on GitHub without running any code.

| File | What it shows | Where it is used |
|---|---|---|
| `fig1_workflow.png` | The six steps from video to comparison. | README, `docs/03_method.md` |
| `fig2_video_to_path.png` | One clip turned into a parametric path. | README |
| `fig3_three_pulls.png` | The three pull paths at the same physical scale. | README, `docs/04_results.md` |
| `fig4_comparison.png` | The typical gap and the shape score. | README, `docs/04_results.md` |
| `fig5_click_checks.png` | The clicks drawn on one frame of each clip. | README, `docs/02_data.md` |

## How they were made

All five are generated by `scripts/make_report_figures.py`:

```bash
python scripts/make_report_figures.py
```

Figures 1, 2, 3, and 4 are built from the committed coordinates. Figure 5 also needs the source videos, which are not committed; if the videos are missing, the script leaves a placeholder in that panel.

## Reading the headline figure

`fig3_three_pulls.png` is the main figure. It draws the pull phase of each clip at the same physical scale. Each open circle is one digitised frame, and each solid line is the fitted polynomial. A2's pull is short, A3's is about the size of Dressel's, and Dressel's curve sits between them.

`fig4_comparison.png` is the second main figure. The left panel is the typical distance from Dressel's path in centimetres. The right panel is the shape score after one overall size adjustment. A3 is closer on both.
